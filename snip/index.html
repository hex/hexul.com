Snip waits in your menu bar. Hold your trigger — the middle mouse button, a thumb button, or a keyboard shortcut — and a ring of snippets blooms under the cursor. It's a lightweight snippet manager and text-expansion tool for the things you retype all day: signatures, addresses, replies, meeting links, code fragments. Tokens like {date} and {clipboard} fill in as they land, and $| marks where the cursor ends up.

Install

$ brew install --cask hex/tap/snip

Or grab the latest notarized zip from GitHub Releases.

Developer ID signed and notarized by Apple.

Snip asks for the macOS Accessibility permission to notice your trigger and paste snippets. Everything stays on your Mac — see privacy.

Features

  • Insert snippets with one gesture
  • Mouse button or keyboard triggers
  • Live magnifier hub
  • Visual ring editor
  • Caret placement & live tokens
  • Works over fullscreen apps
  • Per-app triggers
  • Matches your macOS accent
  • Private: all data local
  • Automatic updates
