# Website

Static HTML product pages served by Cloudflare Pages. The worker routes product subdomains to their directories.

The homepage uses a narrow white layout with text links to the apps. Expand “Claude Code tools” to browse the open-source projects. It uses system fonts and works without JavaScript.

Open `index.html` in a browser to preview the homepage. At mobile widths, each app description sits below its name. Check keyboard focus and expand the tools with Enter or Space.
